# Lumi Vera concept demo

Arabic-first, RTL static storefront concept. This is a presentation prototype, not a working shop.

## Run

Open `index.html` directly, or serve this folder with any static web server. No build step, package install, database or account is needed.

## Deploy

Publish the contents of this folder at the root of a static hosting project. For GitHub Pages, select the `main` branch and `/ (root)` folder. The files use relative URLs and work under a project subdirectory.

## Included

- Scroll-driven CSS 3D packaging, hinged opening and rising cream jar
- Responsive Arabic layout and mobile ordering bar
- Product benefits, original product photography, 20 JOD product price
- Mock cart with quantity controls, totals, clear and close actions
- Reduced-motion support, keyboard focus styling and native modal focus handling
- No analytics, collection of customer details, checkout, payment or real order submission

## Content and assets

Images and brand/product descriptions come from the existing brand website:

- https://lumivera-jo.com/ar
- https://lumivera-jo.com/ar/product
- https://lumivera-jo.com/images/product-front.jpg
- https://lumivera-jo.com/images/brand-flat.jpg

The 3D packaging is a CSS interpretation, not an exact reproduction of the production packaging. No customer reviews, results images or clinical claims have been invented. The testimonials section is an explicitly labeled placeholder until the brand provides approved material. The price and store descriptions should be rechecked before a production launch. Google Fonts is the only third-party runtime resource; system fallback fonts are provided.

## Verified locally

320, 390 and 1280 CSS-pixel layouts, horizontal overflow, image loading, JavaScript errors, quantity 2 = 40 JOD, clearing the cart, Escape closing the cart. Browser rendering has been checked in Chrome. Physical iPhone Safari testing remains a production check.
